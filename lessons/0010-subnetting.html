Part 1 · What the /24 means

On the server, ip -4 addr shows 10.0.0.84/24. You know the first part. The /24 is new.

An IPv4 address is 32 bits (32 ones-and-zeros), written as four numbers of 8 bits each. The number after the slash says how many of those 32 bits are the street name. The rest are the house number.

  • /24 → the first 24 bits (first three numbers, 10.0.0) are the street. The last 8 bits are house numbers.
  • 8 bits of house numbers = 2⁸ = 256 addresses: 10.0.0.0 to 10.0.0.255.

In the village comparison: 10.0.0.0/24 is one street with 256 house numbers. The server lives at house 84.

This “slash number” style is called CIDR notation (Classless Inter-Domain Routing). The same information can be written as a subnet mask: /24 = 255.255.255.0. Each 255 means “this whole number is street name”.

Part 2 · Two addresses you can never give to a computer

On every street, two house numbers are reserved:

  • The first one (10.0.0.0) is the network address: the street's name itself.
  • The last one (10.0.0.255) is the broadcast address: shouting to every house on the street at once.

So a /24 has 256 addresses but only 254 usable hosts (a host is any device that gets an address). The formula: usable hosts = 2(32 − prefix) − 2.

AWS goes further: it reserves 5 addresses in every subnet (the first four and the last one), so an AWS /24 gives you 251. Good to know for Lesson 17 and the SAA exam.

Part 3 · Cutting a street into smaller streets

Why cut? An office with staff PCs, CCTV cameras and guest Wi-Fi shouldn't all live on one street: a guest shouldn't be able to reach the cameras. Each group gets its own smaller street: a subnet.

The table you'll use forever (learn it like a multiplication table):

PrefixMask (last number)Block sizeUsable hosts
/24255.255.255.0256254
/25255.255.255.128128126
/26255.255.255.1926462
/27255.255.255.2243230
/28255.255.255.2401614
/29255.255.255.24886
/30255.255.255.25242

The trick (the “magic number”): block size = 256 − the last mask number. For /26: 256 − 192 = 64. So /26 streets start at 0, 64, 128, 192.

Worked example: which /26 street is 192.168.10.100 on? Block size is 64, so streets start at .0, .64, .128, .192. 100 is between 64 and 127, so it's on the .64 street: network 192.168.10.64 · first usable .65 · last usable .126 · broadcast .127.

Part 4 · Planning addresses for a real building

Let's plan one building. A small office needs staff PCs: 100 devices · CCTV cameras: 40 · guest Wi-Fi: 50. You have 10.20.0.0/24.

Rule: give the biggest group its street first, then go down in size.

GroupNeedsStreetRangeGateway
Staff10010.20.0.0/25.0 – .12710.20.0.1
Guest5010.20.0.128/26.128 – .19110.20.0.129
CCTV4010.20.0.192/26.192 – .25510.20.0.193

Total: 128 + 64 + 64 = 256. It fits exactly. Convention: the router (gateway) takes the first usable address on each street. You'll use this exact plan in Lessons 12, 13, 19 and 21. Try changing the numbers below and watch it stop fitting.

Say it yourself first, then open this

“A /24 is one street of 256 addresses, 254 usable. A bigger slash number means a smaller street. Block size is 256 minus the last mask number. To plan a building I give each group its own subnet, biggest first, so guests, cameras and staff are separated.”
