What does 203.0.113.84:8211 mean?

You’ve typed this into the game to join the game server. It looks like random numbers, but every part has a meaning. By the end of this page you’ll be able to explain all of it to a friend, and you’ll know what people mean by “the cloud”.

≈ 25 minNo experience neededNothing you do here can break the server
How to use this page

Read one part at a time. Every new word is explained the first time it appears, in bold. You don’t need to memorise anything yet: the quizzes at the end do that job.

Part 1 · What is a server?

A server is just a computer that stays switched on and waits for other computers to ask it for something. The computer doing the asking is called the client.

When you play an online game, your laptop is the client. It keeps asking things like “where is my character?” and “did that egg hatch?”. The server holds the game world and answers everyone who is playing. That’s why the world keeps existing even after you log off: the server is still on.

Same idea elsewhere: when you open Facebook, your phone is the client and Facebook’s computers are the servers.

Part 2 · What is “the cloud”?

The server isn’t in your house. It’s a computer in a huge building full of computers in Singapore, owned by Oracle. A building like that is called a data center.

You never touch that computer. You rent it, and control it over the internet from your laptop. That is all “the cloud” really means: renting computers in someone else’s building and using them over the internet. Amazon puts it this way: cloud computing is “the on-demand delivery of IT resources over the Internet with pay-as-you-go pricing.”1

Why do companies do this instead of buying their own computers? Same reason you might rent a condo instead of building a house. You can move in within minutes, pay only for what you use, and someone else fixes the building. Oracle, Amazon (AWS) and Microsoft (Azure) are the big “landlords”.

When you type ssh gameserver on your laptop, you’re using SSH: a remote control that lets you type commands on that computer in Singapore as if you were sitting in front of it.

Part 3 · The IP address: 203.0.113.84

For data to reach a computer, the computer needs an address, like a building needs a street address so the delivery rider can find it. On the internet, that address is called an IP address.

The server’s IP address is 203.0.113.84. This kind of address is always four numbers separated by dots, and each number is between 0 and 255. So 203.0.113.84 is a real address, but 203.0.113.300 can’t be (300 is too big).

Your own laptop and phone have IP addresses too. Every device that uses the internet needs one.

Part 4 · The port: :8211

One computer can run many programs at the same time. The server runs the game, but it also runs the SSH remote control and the monitor. So once data reaches the right computer, it still needs to know which program it is for.

That’s what the port is: a number that picks the program. If the IP address is the condo building’s address, the port is the unit number.2

Port (unit number)Program behind it on the server
8211The game: where players join
22SSH: your remote control

The : just separates the two. So 203.0.113.84:8211 reads as “the computer at 203.0.113.84, the program at port 8211.”

Part 5 · The firewall: the guard at the lobby

Strangers on the internet constantly try random ports, hoping to find one left open, like a thief trying car doors in a parking lot.2 So servers have a firewall: a set of rules saying which ports visitors are allowed to reach. Everything else is turned away.

Think of it as the guard in the condo lobby with a list. The server’s guard list currently allows only unit 22 (SSH) and unit 8211 (the game). That’s why, when we set the server up, we had to “open port 8211”: we were adding the game to the guard’s list.

All together

Say it yourself first, then open this

“The game server runs on a computer we rent from Oracle in Singapore. That’s the cloud. Its IP address, 203.0.113.84, is like the building’s address. The port, 8211, is like the unit number, and it picks the game program. A firewall acts like a lobby guard and only lets visitors through to the ports on its list: 8211 for the game and 22 for SSH, my remote control.”

Practice 3 · Try it on the real server (10 min)

These only look; none of them change anything. Open PowerShell on your laptop (Start menu → type “PowerShell”) and tick each step off.

  • Knock on unit 22. Type this and press Enter:
    Test-NetConnection 203.0.113.84 -Port 22 -InformationLevel Quiet
    It should print True: port 22 is on the guard’s list, and SSH answered.
  • Knock on unit 80. Same command, but -Port 80. Wait about 20 seconds. It prints False: port 80 isn’t on the list, so the guard ignores you. (Why not test 8211? The game talks in a different “style” that this command can’t test. That’s a later lesson.)
  • Step inside. Type ssh gameserver. When the start of the line changes to ubuntu@…, you’re typing on the computer in Singapore.
  • Look around. Type nproc: how many processor cores (the computer’s “brains”) you rent. Then free -h: how much memory (RAM) it has. Look at the total column.
  • Type exit to leave. You’re back on your laptop.
  • Explain it. Without looking, explain 203.0.113.84:8211 out loud to someone (or your phone camera) in under a minute: cloud, IP address, port, firewall.
