Same ideas, AWS names

Most cloud job ads ask for AWS (Amazon Web Services), the biggest cloud provider, and your exam is AWS too. The good news: everything you’ve learned on Oracle carries over. The ideas are the same; only the names change. By the end you can describe the game server in AWS words, plus three ideas every AWS exam asks about: IAM, shared responsibility and pricing.

Warm-up · from Lessons 01–07

Part 1 · Regions and Availability Zones

Every cloud provider has data centers all over the world. A region is one area of the world with its own set of data centers. Your Oracle server is in the Singapore region (ap-singapore-1). AWS also has a Singapore region, named ap-southeast-1.1

Inside a region, AWS keeps several separate data centers called Availability Zones (AZs), far enough apart that a fire or flood in one doesn’t take down the others. Oracle calls them availability domains; yours is AD-1. Companies that can’t afford downtime run copies of their system in two or more zones. That’s called high availability. The game server runs in one zone, which is fine for a game server.

EC2 = Elastic Compute Cloud. EBS = Elastic Block Store. “Elastic” is AWS’s favourite word: it means you can grow or shrink it whenever you need.

Amazon’s two firewalls

Amazon also has two kinds of cloud firewall, and the exam loves the difference:2

Security groupNetwork ACL
Protectsone server (instance)a whole subnet
Rules“allow” rules only“allow” and “deny” rules
Repliesautomatically allowed back: it remembers the conversation (stateful)need their own rule: it judges each packet alone (stateless)

Amazon recommends security groups as the main tool. In the condo comparison, a security group is a guard posted at one building’s door, and a network ACL is the village gate.

Part 3 · IAM: key cards for your cloud account

IAM (Identity and Access Management) controls who can do what in a cloud account: who may create servers, who may see the bills, who may delete things.3 Think of a company issuing key cards:

  • A user is one person (or program) with their own login.
  • A group is a set of users with the same job, like “all developers”.
  • A policy is the written list of what’s allowed, attached to users or groups.
  • A role is a key card that a program or service can borrow temporarily, instead of storing a password.

Two rules every cloud engineer follows: give each person only the access their job needs (least privilege), and never use the root user (the account’s master key) day to day. Lock it with MFA (multi-factor authentication: a code from your phone on top of the password). Do exactly this on day one of any new account.

Part 4 · Shared responsibility: who protects what

Amazon puts it in one line: AWS is responsible for security of the cloud; you are responsible for security in the cloud.4 For the server:

The provider looks after…You look after…
the buildings, power and guardskeeping Ubuntu updated (sudo apt upgrade)
the physical computers and disksboth firewalls’ rules
the network between data centerspasswords, SSH keys and who has access
the virtual machine system itselfyour apps, containers and backups

If the game's admin password leaked, that would be your responsibility, not Oracle’s or Amazon’s.

Part 5 · How cloud pricing works

Cloud is pay-as-you-go: like an electricity meter, you pay for what you use, usually per second or hour. The main things on the bill:

  • Compute: how long servers run, and how big they are.
  • Storage: how much disk you keep, even while a server is switched off.
  • Data transfer: data going out to the internet usually costs; data coming in is usually free. Amazon notes the internet gateway itself is free, but data transfer through it is charged.5

Three habits that keep a learner’s bill at zero:

  1. Set a budget alert before launching anything (a monitoring alert for money).
  2. Stay inside the Free Tier limits, and read them, because they change.
  3. Clean up after every lab. Know the difference between stop (the server is off, but its disk still costs) and terminate (deleted for good, disk included).
Describe the game server in AWS words: say it yourself first, then open this

“It’s like an EC2 instance in the Singapore region, ap-southeast-1, in one Availability Zone, in a public subnet of a VPC with an internet gateway. A security group allows UDP 8211 for the game and TCP 22 for SSH. The OS is Ubuntu, and the game runs in a Docker container with a volume for the save on the EBS disk. Under shared responsibility, AWS secures the hardware, and I secure the OS, the firewall rules, access and backups.”
