Part 3 · CI: a robot that checks every push

Create .github/workflows/lint.yml (in GitHub's web editor: Add file → Create new file, type that path):

name: lint
on: [push]
jobs:
  shellcheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: shellcheck healthcheck.sh

ShellCheck finds common Bash mistakes. GitHub Actions runs it on every push. That's CI (continuous integration) in its smallest form. Afterwards, run git pull on the server to bring that file down.

  • A README.md explains what the script does, how to run it, and what the exit codes mean (write it yourself).
  • At least 5 commits with clear messages by the end of the week (add a check, improve the README, and so on).
  • You can explain every line of the script out loud without notes.
