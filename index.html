How to use this course

One lesson per study night is plenty. Every lesson starts with a warm-up on earlier lessons, because recalling something days later is what makes it stick. Each page is a stack of numbered sheets with an XP bar at the top: quizzes, simulators, drills, sorting games and break/fix tickets all earn XP. Practise in the page first, then do it for real.

Nothing on these pages can touch the real server. Lab steps say look only or changes the server so you always know.

Suggested order with your 12-week tracker

Weeks 1–4 networking: Lessons 01–03, then 10–13 · Week 5: Lessons 04 and 14 · Week 6: Lessons 05–07 and 15 · Week 7: Lessons 19, 20 and 21, and start applying · Weeks 8–10 AWS: Lessons 08, 16, 17 · Week 11: Lessons 09 and 18 · Week 12: exam, mock interviews, review the Application Tracker. Bridge jobs (data center, NOC, ELV) don't need AWS, so applying starts before the AWS weeks. Book the CCNA when you score 85% or more on two Boson ExSim practice exams.

Move my progress

Your XP, quiz scores and ticks are saved in this browser only. To carry on with another device:

  1. On the device with your progress, tap Make my progress code, then Copy.
  2. Send the code to yourself (Messenger, email, notes).
  3. On the other device, open this page, paste the code below and tap Add to this device.

The two are combined: the better result for each quiz, game and tick is kept, so nothing on either device is lost. Do it both ways to keep them the same. The code stays with you; nothing is sent anywhere.
