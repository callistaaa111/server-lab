# Server Lab

A hands-on networking, data center and cloud course in 21 lessons: subnetting, DNS/DHCP, VLANs, routing,
data center power and cooling, NOC work, AWS, Terraform, scripting, and Cisco ACLs. Every lesson has quizzes,
simulators and games. Progress and XP are saved in your browser only.

Open `index.html`, or visit the GitHub Pages site.
