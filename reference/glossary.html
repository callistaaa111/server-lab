Word list

Every word the course teaches, in plain language, with an example from your server. Grey tags give the AWS name where it differs. Grouped by the lesson that teaches it.

01 · Decode your join address

Server / client
A computer that stays on and answers requests / the computer that asks.The Oracle computer in Singapore / your laptop.
Cloud
Renting computers in someone else’s building and using them over the internet, paying for what you use.Oracle, AWS (Amazon) and Azure (Microsoft) are cloud providers.
Data center
A large building full of computers.Oracle’s data center in Singapore.
IP address
A computer’s address on a network: four numbers, 0–255 each.203.0.113.84: the building’s street address.
Port
A number that picks which program on a computer the data is for.8211 = Palworld, 22 = SSH: the unit number.
Firewall
Rules for which ports visitors may reach; everything else is blocked.The lobby guard with a list.
SSH
A secure remote control for typing commands on another computer (TCP port 22).ssh gameserver

02 · Your server has two addresses

Network
A group of connected devices that can talk to each other.
Public / private IP address
Works across the whole internet / works only inside one network.203.0.113.84 / 10.0.0.84. Private ranges start with 10., 172.16–31. or 192.168.
NAT (Network Address Translation)
Swapping public and private addresses as data passes through.The receptionist transferring outside calls to extensions.
Internet gateway
The door between a cloud private network and the internet; it does the NAT.
Default gateway
Where a device sends anything it doesn’t know how to reach.Your home router; 10.0.0.1 for the server.
Subnet
A block of neighbouring addresses, like one street.10.0.0.0/24 = every address starting 10.0.0.

03 · TCP and UDP

Packet
A small piece of data carrying its destination address and port.
Protocol
An agreed set of rules for communicating.
TCP
The reliable protocol: handshake, confirms, resends, keeps order.SSH, websites. The registered courier.
UDP
The fast protocol: just sends, with no confirmations.Palworld, voice, video. Shouting updates.
Handshake
TCP’s hello exchange that sets up a connection.
Listening
A program waiting for packets on a port.See them with sudo ss -tulpn.
Localhost (127.0.0.1)
“This computer itself”: reachable only from inside.Your monitor listens on 127.0.0.1:8797.

04 · Linux basics

Operating system (OS)
The base software that runs everything else.Windows on your laptop, Ubuntu Linux on the server.
Terminal / shell / prompt
The text window / the program that runs what you type / the user@machine:folder$ line.
Directory / path
A folder / its location./opt/palworld
root / sudo
The administrator account / run one command as administrator.The building manager’s key card.
Permissions
Who may read (r), write (w) or run (x) a file.rw------- on the compose file: only root.
RAM / disk
Short-term working memory, wiped on reboot / long-term storage.
Service
A program that runs in the background all the time.palworld-monitor

05 · Docker

Container
An isolated running program with all the files it needs; shares the server’s OS.The sealed room palworld at 172.18.0.2.
Image
The packed kit a container is built from.thijsvanloef/palworld-server-docker
Virtual machine (VM)
A whole pretend computer with its own OS, carved out of a real one.Your Oracle server.
Docker Compose / YAML
Writing a container’s setup in a file / the indentation-sensitive format that file uses.
Port mapping
Forwarding a server port into a container.8211:8211/udp
Volume
Storage outside a container that survives when it’s replaced../data:/palworld
Configuration as code
Keeping setup in files instead of clicks, so it can be repeated and reviewed.

06 · Follow a packet

Security list AWS: network ACL (subnet) · security group (server)
Oracle’s firewall, outside the server, set on the website for a subnet.The village gate guard.
iptables
The Linux firewall inside the server.The lobby guard; ends with “reject the rest”.
Troubleshooting (outside-in)
Checking one layer at a time from the internet towards the program, stopping at the first failure.

07 · Monitoring & backups

Monitoring / metric / dashboard
Watching numbers over time / one such number / a screen of charts.
Four golden signals
Latency, traffic, errors, saturation.
Alert
A message that a human needs to act. Good alerts are rare.
Health check
A regular “are you OK?” question to a program.(healthy) in docker ps.
Auto-remediation
The system fixing a known problem by itself.Restart when memory runs low.
systemd / cron
Starts services at boot and keeps them up / runs jobs on a schedule (45 4 * * *).
Backup / retention
A copy to go back to / how long copies are kept (7 days).
RPO / RTO
Most data you can afford to lose / most downtime you can accept.
3-2-1 rule
3 copies, on 2 kinds of storage, 1 kept somewhere else.

08 · Same ideas, AWS names

Region / availability domain AWS: Region / Availability Zone (AZ)
An area of the world / a separate data center inside it.ap-singapore-1 (AWS: ap-southeast-1).
High availability
Running copies in more than one zone so one failure doesn’t stop the service.
Tenancy AWS: account
Your top-level cloud account.
VCN AWS: VPC
Your own private network in the cloud.
Compute instance / shape AWS: EC2 instance / instance type
A rented virtual computer / its size.
Boot volume AWS: EBS volume
The virtual computer’s disk.
Reserved public IP AWS: Elastic IP
A public address that stays yours until you release it.
Stateful / stateless
Remembers the conversation and lets replies back / judges each packet alone.
IAM
Who can do what in a cloud account: users, groups, policies, roles.
Least privilege / root user / MFA
Only the access needed / the account’s master key / a phone code on top of the password.
Shared responsibility model
The provider secures the cloud itself; you secure what you put in it.
Pay-as-you-go / Free Tier / budget alert
Pay for what you use / free usage limits / a notification when spending passes a limit.
