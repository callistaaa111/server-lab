Command cheat sheet

Every command from the lessons. LOOK = only reads, always safe. CHANGES = does something; check who’s online first.

On your laptop (PowerShell)

CommandWhat it doesLesson
ssh gameserverLog in to the server (remote control). exit to leave.LOOK01
Test-NetConnection 203.0.113.84 -Port 22 -InformationLevel QuietKnock on a TCP port. True = answered. Can’t test UDP (8211).LOOK01, 03
ipconfigYour laptop’s private IP and default gateway (router).LOOK02
